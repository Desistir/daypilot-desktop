# Privacy policy

DayPilot stores tasks, notes, completion history, reminder state and settings locally in SQLite. It does not intentionally transfer task information to networked systems, include analytics, or synchronize with a cloud service.

Backups remain local. Do not upload your database, backups, logs or screenshots with personal information when reporting bugs. The public source contains no personal task data.

If you configure an MCP client, that client can access task content through the configured local stdio connection. Its handling of information is governed by that client's policies. Connecting it is optional.

Autostart is optional and changes the Windows login startup setting only when enabled by the user. Popup reminders are silent. Closing the main window keeps the tray process running; use the tray menu to quit completely.

Development and CI use package registries and GitHub infrastructure to download dependencies and build source. These are separate from use of the desktop application.
